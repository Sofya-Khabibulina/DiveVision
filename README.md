# DiveVision
**Веб-приложение для автоматизированного анализа техники выполнения прыжков в воду с помощью компьютерного зрения.**

## О проекте

DiveVision — это проект веб-сервиса для тренеров и спортсменов по прыжкам в воду. Сервис предназначен для анализа видеозаписей тренировок, оценки техники выполнения прыжков и отслеживания прогресса спортсменов.

С помощью технологий компьютерного зрения система должна автоматически определять ключевые фазы прыжка — заход, отталкивание, полёт и вход в воду — и рассчитывать характеристики выполнения. Результаты анализа предполагается представлять в виде числовых показателей, графиков и сравнений различных попыток.

## Цель проекта

Разработать веб-интерфейс, который позволит тренерам удобно работать с видеозаписями прыжков в воду, просматривать результаты анализа и отслеживать динамику подготовки спортсменов.

## Основные возможности

- Просмотр информации о спортсменах.

- Загрузка и хранение видеозаписей тренировок.

- Просмотр результатов анализа техники выполнения прыжков.

- Визуализация характеристик прыжка с помощью графиков и числовых показателей.

- Сравнение нескольких попыток одного спортсмена.

- Отслеживание изменений результатов в процессе тренировок.


## Целевая аудитория

- Тренеры по прыжкам в воду.

- Спортсмены, занимающиеся прыжками в воду.

- Спортивные организации, заинтересованные в цифровизации тренировочного процесса.

## Технологии

В рамках учебного проекта предусматривается разработка прототипа веб-интерфейса с использованием HTML, CSS и JavaScript, а также проектирование пользовательских сценариев и интерфейса в Figma.

## Тестирование

Для проверки качества веб-интерфейса разрабатываются тест-кейсы, охватывающие основные пользовательские сценарии: навигацию между страницами, взаимодействие с кнопками и элементами интерфейса, просмотр информации, загрузку видео и отображение состояний системы.

## Статус проекта

Проект находится на этапе проектирования и разработки веб-интерфейса. Функциональность автоматического анализа видео с помощью компьютерного зрения может развиваться отдельно от пользовательского прототипа.
