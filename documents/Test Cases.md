## **TC-08. Загрузка корректного видео**

P1 · Высокий

Категория: функциональное тестирование

Предусловия:

* Пользователь находится в интерфейсе DiveVision.  
* Доступен экран загрузки видео.  
* Подготовлен тестовый файл допустимого формата и размера.

Тестовые данные:

Например, MP4-файл размером 20 МБ, если этот формат и размер разрешены системой.

Шаги выполнения:

1. Открыть раздел загрузки видео.  
2. Нажать на элемент выбора файла.  
3. Выбрать подготовленный тестовый файл.  
4. Подтвердить загрузку.  
5. Дождаться окончания процесса.  
6. Проверить появившийся статус и доступность загруженного видео.

Ожидаемый результат:

* Файл успешно принимается системой.  
* Отображается состояние загрузки.  
* После завершения показывается подтверждение.  
* Видео появляется в предусмотренном разделе.  
* Пользователь может перейти к дальнейшей работе с попыткой.

## **TC-14. Сравнение двух попыток**

P1 · Высокий

Категория: функциональное тестирование

Предусловия:

* В системе доступны две попытки одного спортсмена.  
* Для обеих попыток завершён анализ.  
* Данные содержат сопоставимые метрики.

Шаги выполнения:

1. Открыть раздел сравнения попыток.  
2. Выбрать первую попытку.  
3. Выбрать вторую попытку.  
4. Подтвердить сравнение.  
5. Проверить отображение данных и обозначения каждой попытки.

Ожидаемый результат:

* Отображаются именно выбранные попытки.  
* Метрики каждой попытки соответствуют её результатам анализа.  
* Графики, подписи и числовые значения не перепутаны.  
* Пользователь может визуально определить различия между попытками.

## **TC-09. Загрузка неподдерживаемого файла**

P1 · Высокий

Категория: негативное тестирование

Предусловия:

* Открыт экран загрузки видео.  
* Подготовлен файл формата, который не поддерживается системой.

Шаги выполнения:

1. Нажать на элемент выбора файла.  
2. Выбрать файл неподдерживаемого формата.  
3. Попытаться продолжить загрузку.  
4. Проверить реакцию интерфейса.

Ожидаемый результат:

* Система отклоняет неподдерживаемый файл.  
* Пользователь видит сообщение с причиной отказа.  
* Можно выбрать другой файл.  
* Ошибка не приводит к зависанию или потере ранее сохранённых данных.
